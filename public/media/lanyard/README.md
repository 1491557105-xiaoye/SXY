# Lanyard assets

Replace these files while keeping the same names:

- `card-front.svg`: front of the ID card, recommended 1000 × 1400 px (5:7).
- `card-back.svg`: back of the ID card, recommended 1000 × 1400 px (5:7).
- `lanyard.png`: repeating lanyard texture. A seamless horizontal pattern works best.

Keep `card.glb`; it is the physical card model used by the interaction.

Transparent PNG or SVG artwork is supported. Export all text as outlines when using SVG to avoid missing-font differences.
